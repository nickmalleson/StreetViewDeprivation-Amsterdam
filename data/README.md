# Data

Most data files are generated by running the pipeline (the imagery is downloaded by
`panorama_acquisition.py`; the boundaries and SES-WOA target are downloaded/cached by
`amsterdam_data.py`). They are git-ignored (`data/*` except this README) and can be large.

See [`../DATA_PROVENANCE.md`](../DATA_PROVENANCE.md) for sources, licences and attribution.

## Expected directory structure

```
data/
├── raw/
│   ├── panorama_worklist.parquet            # canonical work list (built by panorama_acquisition.py)
│   ├── panorama_worklist.parquet.meta.json  # settings the work list was built with (drives auto-rebuild)
│   ├── panorama_manifest.csv                # completed pano_ids (resumable-download state)
│   ├── panorama_images/                     # cached N/E/S/W crops: <pano_id>/h{000,090,180,270}.jpg
│   └── spatial/
│       └── buurten_2024/
│           └── amsterdam_buurten_2024.gpkg  # CBS WijkBuurtkaart 2024 buurten (Amsterdam), via PDOK
├── processed/
│   ├── street_data.h5                       # HDF5 data store (images, embeddings, metadata, provenance)
│   ├── ses_woa_86092NED.csv                 # CBS SES-WOA target per buurt (cached from OData)
│   ├── one_row_per_image_cleaned.pkl        # Output of notebook 3
│   ├── one_row_per_image_cleaned_with_cluster_numbers.pkl  # Output of notebook 5
│   ├── per_buurt_embedding_summaries/
│   │   ├── mean_embedding.pkl
│   │   ├── median_embedding.pkl
│   │   └── alphaearth_embeddings.pkl        # Output of notebook 9a
│   ├── alphaearth_tiles/                    # AlphaEarth GeoTIFF tiles (manually downloaded for 9a)
│   └── alphaearth_amsterdam_2023.tif.gz     # merged AlphaEarth GeoTIFF (9a)
└── models/
    ├── best_model.joblib                    # Output of notebook 4
    ├── best_model_alphaearth.joblib         # Output of notebook 9b
    └── model_testing/
        └── cluster_subsample_results.pkl    # Output of notebook 6
```

## Data sources

- **Street-level imagery**: City of Amsterdam Open Panorama ("Kernregistratie panoramabeelden"),
  CC-BY 4.0, via `https://api.data.amsterdam.nl/panorama/`. Downloaded by `panorama_acquisition.py`.
- **Deprivation (SES-WOA)**: CBS StatLine table 86092NED, via the CBS open-data (OData) API.
  Downloaded/cached by `amsterdam_data.get_ses_woa()`.
- **Buurt boundaries**: CBS WijkBuurtkaart 2024 via PDOK WFS. Downloaded/cached by
  `amsterdam_data.get_amsterdam_buurten()`.
- **Satellite embeddings**: Google DeepMind AlphaEarth via Google Earth Engine (notebook 9a; requires
  GEE auth + a manual GeoTIFF download).

## Notes

- Everything under `processed/` and `models/` is generated by running the notebooks in sequence; the
  imagery under `raw/panorama_images/` is downloaded by the acquisition script. There are no manual
  external inputs except the AlphaEarth GeoTIFF tiles for notebook 9a.
- The downloader is fully resumable: re-running `panorama_acquisition.py` only fetches points not
  already completed (tracked in `panorama_manifest.csv`).
